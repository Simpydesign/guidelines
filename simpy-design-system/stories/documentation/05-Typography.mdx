# Tipografia

O sistema tipográfico do Simpy Design System é projetado para criar hierarquia clara e legibilidade
em todos os tamanhos de tela, com **Poppins** como fonte oficial.

## Famílias Tipográficas

### Poppins (Fonte Oficial)

```css
font-family: 'Poppins', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

**Poppins** é a fonte oficial do Simpy Design System, usada em toda a interface.

**Características:**
- Formas geométricas modernas e amigáveis
- Excelente legibilidade em telas de todos os tamanhos
- Ampla variedade de pesos (300-800)
- Suporte a múltiplos idiomas
- Visual limpo e profissional
- Otimizada para interfaces digitais

**Quando usar:**
- Todo texto de interface (padrão)
- Títulos e headings
- Botões e labels
- Formulários e inputs
- Corpo de texto
- Navegação

**Origem:**
Poppins foi projetada por Indian Type Foundry e é uma das fontes geométricas sans-serif mais populares
do Google Fonts. [Ver no Google Fonts →](https://fonts.google.com/specimen/Poppins)

---

### Fira Code (Monoespaçada)

```css
font-family: 'Fira Code', 'Courier New', monospace;
```

**Fira Code** é usada exclusivamente para código e dados técnicos.

**Quando usar:**
- Blocos de código
- Valores numéricos técnicos
- Logs e debugging
- Dados tabulares
- Terminal output

## Hierarquia Tipográfica

### Títulos (Headings)

```css
/* H1 - Título Principal */
font-size: 3rem (48px)
font-weight: 800
line-height: 1.2
font-family: Poppins

/* H2 - Título de Seção */
font-size: 2.25rem (36px)
font-weight: 700
line-height: 1.25
font-family: Poppins

/* H3 - Subtítulo */
font-size: 1.875rem (30px)
font-weight: 600
line-height: 1.3
font-family: Poppins

/* H4 - Título Menor */
font-size: 1.5rem (24px)
font-weight: 600
line-height: 1.4
font-family: Poppins

/* H5 - Título de Card */
font-size: 1.25rem (20px)
font-weight: 600
line-height: 1.5
font-family: Poppins

/* H6 - Menor Título */
font-size: 1.125rem (18px)
font-weight: 600
line-height: 1.5
font-family: Poppins
```

### Corpo de Texto (Body)

```css
/* Body Large */
font-size: 1.125rem (18px)

font-size: 0.875rem (14px)

font-family: Poppins

/* Caption */
font-size: 0.75rem (12px)
font-weight: 400
line-height: 1.5
font-family: Poppins
color: #6B7280
```

## Diretrizes de Uso

### Legibilidade

**Comprimento de Linha:**
- Texto ideal: 50-75 caracteres por linha
- Máximo: 90 caracteres
- Mínimo: 40 caracteres

**Line Height (Espaçamento entre linhas):**
- Títulos: 1.2 - 1.3 (tight/snug)
- Corpo de texto: 1.5 - 1.625 (normal/relaxed)
- Texto denso: 1.75 - 2 (loose)

### Contraste

- Texto principal: `neutral.900` em fundo claro
- Texto secundário: `neutral.600` ou `neutral.700`
- Texto terciário: `neutral.500`

Sempre mantenha contraste mínimo de **4.5:1** para texto normal.

### Hierarquia

Use a hierarquia tipográfica para guiar o olhar:

1. **Título principal (H1)** - Um por página
2. **Títulos de seção (H2)** - Separam grandes blocos
3. **Subtítulos (H3-H4)** - Organizam conteúdo dentro de seções
4. **Corpo de texto** - Conteúdo principal
5. **Captions e notas** - Informações suplementares

### Responsividade

Ajuste tamanhos em breakpoints menores:

```css
/* Desktop */
h1 { font-size: 3rem; }
h2 { font-size: 2.25rem; }
body { font-size: 1rem; }

/* Tablet */
@media (max-width: 1024px) {
  h1 { font-size: 2.5rem; }
  h2 { font-size: 2rem; }
}

/* Mobile */
@media (max-width: 640px) {
  h1 { font-size: 2rem; }
  h2 { font-size: 1.5rem; }
  body { font-size: 0.875rem; }
}
```

## Importando a Fonte

### Google Fonts CDN

Adicione no `<head>` do seu HTML:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
```

### CSS @import

```css
@import url('https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700;800&display=swap');
```

### NPM Package (opcional)

```bash
npm install @fontsource/poppins
```

```tsx
import '@fontsource/poppins/300.css';
import '@fontsource/poppins/400.css';
import '@fontsource/poppins/500.css';
import '@fontsource/poppins/600.css';

```

## Implementação

### Importando Tokens

```tsx
import { typography } from 'simpy-design-system/tokens';

const Heading = styled.h1`
  font-family: ${typography.fontFamily.primary};
  font-size: ${typography.fontSize['4xl']};
  font-weight: ${typography.fontWeight.bold};
  line-height: ${typography.lineHeight.tight};
`;
```

### CSS Variables

```css
:root {
  --font-primary: 'Poppins', sans-serif;
  --font-mono: 'Fira Code', monospace;

  --text-xs: 0.75rem;
  --text-sm: 0.875rem;
  --text-base: 1rem;
  --text-lg: 1.125rem;

  --weight-light: 300;
  --weight-regular: 400;
  --weight-medium: 500;
  --weight-semibold: 600;
  --weight-bold: 700;
  --weight-extrabold: 800;
}

body {
  font-family: var(--font-primary);
  font-size: var(--text-base);
  font-weight: var(--weight-regular);
}
```

## Acessibilidade

✅ **Boas práticas:**
- Use tamanho mínimo de 16px para texto principal
- Mantenha contraste adequado (4.5:1 para texto, 3:1 para texto grande)
- Evite texto todo em maiúsculas (dificulta leitura)
- Permita zoom até 200% sem quebrar layout
- Não use apenas cor para transmitir informação

❌ **Evitar:**
- Texto menor que 12px
- Cinza claro em fundo branco
- Comprimento de linha muito longo
- Line height muito apertado (<1.2)
