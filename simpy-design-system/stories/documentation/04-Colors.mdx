# Cores

O sistema de cores do Simpy Design System é projetado para criar interfaces visuais consistentes,
acessíveis e expressivas.

## Diretrizes de Uso

### Contraste e Acessibilidade

Todas as combinações de cores devem atender aos padrões WCAG 2.1 AA:

- **Texto normal:** Contraste mínimo de 4.5:1
- **Texto grande (18px+):** Contraste mínimo de 3:1
- **Elementos de UI:** Contraste mínimo de 3:1

#### Combinações Recomendadas:

✅ **Boas combinações:**
- `neutral.900` em `neutral.50` (texto escuro em fundo claro)
- `white` em `primary.600` (texto claro em fundo escuro)
- `neutral.700` em `white` (texto médio em fundo branco)

❌ **Evitar:**
- `neutral.400` em `white` (contraste insuficiente)
- `warning.300` em `white` (contraste insuficiente)
- `primary.400` em `secondary.400` (cores similares)

### Hierarquia Visual

Use a escala de tons para criar hierarquia:

- **500-600:** Elementos primários e de maior destaque
- **400-500:** Elementos secundários
- **300-400:** Elementos de suporte
- **100-200:** Backgrounds e estados hover
- **50-100:** Backgrounds sutis

### Uso de Cor em Fundos

```css
/* Fundos de página */
background: neutral.50

/* Cards e containers */
background: white
border: neutral.200

/* Elementos em hover */
background: primary.50
border: primary.200

/* Estados ativos */
background: primary.100
border: primary.300
```

### Uso de Cor em Texto

```css
/* Texto principal */
color: neutral.900

/* Texto secundário */
color: neutral.600

/* Texto terciário/hints */
color: neutral.500

/* Texto desabilitado */
color: neutral.400
```

## Implementação no Código

### Importando as Cores

```tsx
import { colors } from 'simpy-design-system/tokens';

const Button = styled.button`
  background-color: ${colors.primary[500]};
  color: ${colors.white};

  &:hover {
    background-color: ${colors.primary[600]};
  }

  &:disabled {
    background-color: ${colors.neutral[300]};
    color: ${colors.neutral[500]};
  }
`;
```

### Usando com CSS Variables

```css
:root {
  --color-primary: #6366F1;
  --color-primary-hover: #4F46E5;
  --color-text: #1F2937;
  --color-background: #F9FAFB;
}

.button {
  background-color: var(--color-primary);
  color: white;
}
```

## Modo Escuro (Dark Mode)

O Simpy Design System suporta modo escuro. Use as variantes mais escuras das cores neutras:

- **Fundo:** `neutral.900`
- **Cards:** `neutral.800`
- **Texto:** `neutral.50`
- **Texto secundário:** `neutral.300`
- **Bordas:** `neutral.700`

---

**Dica:** Use ferramentas como [Contrast Checker](https://webaim.org/resources/contrastchecker/)
para verificar se suas combinações de cores são acessíveis.
