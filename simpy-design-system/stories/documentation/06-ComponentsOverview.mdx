## 🎯 Como Usar

### 1. Instalação

```bash
npm install simpy-design-system
```

### 2. Importação

```tsx
import { Button, Input, Card } from 'simpy-design-system';
import 'simpy-design-system/dist/styles.css';
```

### 3. Uso

```tsx
function MeuFormulario() {
  return (
    <Card>
      <Input
        label="Nome"
        placeholder="Digite seu nome"
      />
      <Button variant="primary">
        Enviar
      </Button>
    </Card>
  );
}
```

## 📋 Padrões de Uso

### Props Comuns

Todos os componentes seguem padrões consistentes:

#### Size (Tamanho)
```tsx
size?: 'sm' | 'md' | 'lg'
```
- **sm:** Compacto, para espaços limitados
- **md:** Padrão, uso geral
- **lg:** Grande, para destaque

#### Variant (Variante)
```tsx
variant?: 'primary' | 'secondary' | 'outline' | 'ghost'
```
Define o estilo visual do componente

#### Disabled (Desabilitado)
```tsx
disabled?: boolean
```
Desabilita interação com o componente

#### FullWidth (Largura Total)
```tsx
fullWidth?: boolean
```
Faz o componente ocupar 100% da largura disponível

### Acessibilidade

Todos os componentes incluem:

- ✅ ARIA labels apropriados
- ✅ Navegação por teclado
- ✅ Estados de foco visíveis
- ✅ Suporte a leitores de tela
- ✅ Semântica HTML correta

### TypeScript

Todos os componentes têm tipos TypeScript completos:

```tsx
import { ButtonProps, InputProps } from 'simpy-design-system';

const minhasPropsBotao: ButtonProps = {
  variant: 'primary',
  size: 'md',
  children: 'Clique aqui'
};
```

## 🎨 Customização

### Usando com Styled Components

```tsx
import styled from 'styled-components';
import { Button } from 'simpy-design-system';

const CustomButton = styled(Button)`
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

  &:hover {
    transform: scale(1.05);
  }
`;
```

### Sobrescrevendo Estilos com CSS

```css
.simpy-button.meu-botao-custom {
  background-color: #custom-color;
  border-radius: 20px;
}
```

## 💡 Dicas de Performance

### Tree Shaking

Importe apenas os componentes que você precisa:

```tsx
// ✅ Bom - apenas Button é incluído no bundle
import { Button } from 'simpy-design-system';

// ❌ Evitar - importa toda a biblioteca
import * as Simpy from 'simpy-design-system';
```

### Lazy Loading

Para componentes grandes, use lazy loading:

```tsx
import { lazy, Suspense } from 'react';

const Card = lazy(() => import('simpy-design-system').then(m => ({ default: m.Card })));

function App() {
  return (
    <Suspense fallback={<div>Carregando...</div>}>
      <Card>Conteúdo</Card>
    </Suspense>
  );
}
```
